About the six models

stage 03 detail

Each disease has its own logistic regression, trained only on the features clinically relevant to it, with its own tuned decision threshold (chosen to prioritize recall — a screening tool should rarely miss a true case, at the cost of more false alarms). Test-set metrics from the actual training run:

AUC in the 0.75–0.85 range with recall around 0.80–0.90 is the realistic, intended result for symptom-and-labs prediction — not a shortfall. A model claiming near-perfect accuracy on this kind of data would be a red flag, not a good sign.
